# K1Motion

نرم‌افزار سبک و رایگان برای پایش حرکت دوربین‌های IP (RTSP) روی ویندوز.

با K1Motion می‌توانید چند دوربین را همزمان ببینید، برای هرکدام یک محدوده (ROI) تعیین کنید،
و هر وقت چیزی در آن محدوده حرکت کرد، هشدار بگیرید، فیلم کوتاه ضبط کنید و حتی آن را
خودکار به پیام‌رسان **بله** بفرستید.

---

## ✨ امکانات

- 🎥 اتصال به چند دوربین RTSP به‌صورت همزمان
- 🧩 نمای شبکه‌ای (۲×۲ تا ۵×۵) با دابل‌کلیک برای بزرگ‌نمایی
- 🎯 تعیین محدوده (ROI) با ماوس روی تصویر
- ⚡ تشخیص حرکت سبک روی CPU (بدون نیاز به GPU یا AI)
- 🔔 آلارم تمام‌صفحه + صدای هشدار + کادر قرمز روی محل حرکت
- 🎬 ضبط خودکار فیلم هنگام حرکت (مدت قابل تنظیم)
- 📨 ارسال خودکار فیلم به پیام‌رسان **بله** با پخش آنلاین
- 🔽 مخفی‌سازی در سینی سیستم کنار ساعت
- 🔊 کنترل بلندی صدا
- 💾 ذخیره‌ی همه تنظیمات بین اجراها
- 🖥️ خروجی EXE تک‌فایلی بدون نیاز به نصب پایتون

## 🚀 نصب و اجرا

### روش ۱: اجرای مستقیم از سورس

```bash
pip install PySide6 opencv-python numpy imageio-ffmpeg requests
python k1motion.py
```

### روش ۲: استفاده از EXE آماده

از بخش [Releases](../../releases) فایل `K1Motion.exe` را دانلود و اجرا کنید.
هیچ نصب اضافی نیاز نیست.

## 📖 راهنمای سریع

1. **افزودن دوربین** — روی «➕ افزودن» بزنید، IP / Port / User / Password را وارد کنید.
   اگر مسیر RTSP را نمی‌دانید، دکمه **«🔍 تشخیص خودکار»** را بزنید.
2. **اتصال** — روی «🔌 اتصال» یا «🔗 اتصال به همه» بزنید.
3. **تعیین محدوده** — روی «▭ تعیین محدوده» بزنید و با ماوس روی تصویر یک کادر بکشید.
4. **تنظیم حساسیت** — از اسلایدر ستون چپ استفاده کنید.
   - اگر با برگ یا سایه آلارم می‌دهد → «حداقل ناحیه حرکت» را زیاد کنید.
   - اگر آدم رد می‌شود و آلارم نمی‌دهد → آن را کم کنید.
5. **تنظیمات بله** — در «⚙ تنظیمات عمومی» توکن ربات و Chat ID را وارد کنید.

### ساخت ربات بله

1. در پیام‌رسان بله به [@BotFather](https://ble.ir/BotFather) پیام دهید.
2. دستور `/newbot` را بزنید و توکن را دریافت کنید.
3. به ربات خود یک پیام بفرستید.
4. در مرورگر این آدرس را باز کنید و `TOKEN` را جایگزین کنید:
   ```
   https://tapi.bale.ai/botTOKEN/getUpdates
   ```
5. عدد `"id"` در بخش `"chat"` همان **Chat ID** شماست.

## 🛠️ ساخت EXE

```bash
pip install pyinstaller imageio-ffmpeg
pyinstaller --noconfirm --clean --onefile --windowed ^
  --name "K1Motion" ^
  --icon "icon.ico" ^
  --collect-all imageio_ffmpeg ^
  --collect-all cv2 ^
  --hidden-import PySide6.QtMultimedia ^
  --hidden-import PySide6.QtNetwork ^
  --hidden-import pyrobale ^
  --exclude-module tkinter ^
  --exclude-module matplotlib ^
  --exclude-module scipy ^
  --exclude-module pandas ^
  k1motion.py
```

خروجی: `dist/K1Motion.exe`

## ⚙️ تنظیمات کجا ذخیره می‌شوند؟

همه‌ی تنظیمات (توکن بله، Chat ID، آدرس دوربین‌ها، ROI، ...) در این مسیر ذخیره می‌شوند:

```
C:\Users\<YourUser>\.k1motion\settings.json
```

فیلم‌های ضبط‌شده به‌صورت پیش‌فرض اینجا هستند:

```
C:\Users\<YourUser>\.k1motion\recordings\
```

این اطلاعات **داخل exe نیستند** و روی هر سیستمی که برنامه را اجرا کنید، جداگانه ساخته می‌شوند.

## ❓ سوالات متداول

**آیا به GPU نیاز دارد؟**
نه. تشخیص حرکت با Background Subtraction روی CPU اجرا می‌شود و برای یک دوربین معمولی مصرف CPU بسیار کمی دارد.

**چند دوربین را می‌توانم وصل کنم؟**
محدودیت نرم‌افزاری ندارد. فقط بر اساس قدرت سیستم و پهنای‌باند شبکه.

**آیا روی لینوکس/مک کار می‌کند؟**
کد اصلی پایتون بله، ولی دکمه سینی و صدای هشدار به‌طور کامل فقط روی ویندوز تست شده.

**رمز دوربین امن است؟**
رمز در فایل `settings.json` روی سیستم خودتان به‌صورت plain ذخیره می‌شود. اگر نگران هستید، آن را با ابزارهای رمزنگاری ویندوز محافظت کنید.
